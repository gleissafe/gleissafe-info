# Release Checkliste

## Technischer Stand

- [x] TestFlight Build 20 erstellt
- [x] Build 20 auf iPad getestet
- [x] Handbuch-Link korrigiert
- [x] Smoke-Test bestanden
- [x] GitHub Pages Supportseite erstellt
- [x] App Store Grunddaten vorbereitet
- [x] Store Texte vorbereitet
- [x] Screenshot-Plan vorbereitet

## Vor App Store Connect

- [x] App Icon final prüfen
- [x] iPad Screenshots erstellen
- [ ] iPhone Screenshots (nicht vergessen - iPhone dient nur Entwicklung/Test)
- [ ] Datenschutzangaben in App Store Connect ausfüllen
- [ ] Support-URL eintragen
- [ ] Datenschutz-URL eintragen
- [ ] App-Beschreibung eintragen
- [ ] Review Notes vorbereiten

## Vor Unlisted App Antrag

- [ ] App bei Apple Review einreichen
- [ ] App darf nicht als Beta beschrieben sein
- [ ] App muss review-ready sein
- [ ] Nach Freigabe Unlisted App Antrag stellen

## Nicht erneut anfassen ohne Grund

- [ ] Dispo 1–9 Logik
- [ ] PDF Templates
- [ ] PDF Exportpositionen
- [ ] Nachweis-/Archivlogik
- [ ] Paket-Teilen
